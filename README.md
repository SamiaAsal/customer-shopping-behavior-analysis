# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior to identify purchasing patterns, product preferences, and sales trends. The goal is to transform raw customer data into actionable business insights using Python and Power BI.

## Objectives
- Analyze customer purchasing behavior and spending patterns.
- Identify popular product categories and products.
- Explore customer preferences, including product sizes.
- Build an interactive Power BI dashboard to support data-driven decisions.

## Tools & Technologies
- **Python:** Data analysis and exploratory data analysis (EDA)
- **Pandas:** Data manipulation and cleaning
- **Matplotlib / Seaborn:** Data visualization
- **Power BI:** Interactive dashboard and business reporting
- **Jupyter Notebook:** Analysis workflow

## Dataset
The project uses a customer shopping behavior dataset containing customer and purchase-related information.

The dataset contains 3,900 records and 21 columns.

*Note: Dataset redistribution rights should be verified before publishing the raw data.*

## Key Findings
- Clothing was the highest-selling category by purchase amount in the analyzed dataset.
- The Blouse product recorded the highest purchase amount within the Clothing category.
- Product size analysis indicated that size M was frequently purchased.
- The analysis explored differences in purchasing behavior across customer groups and product categories.

*Findings should be interpreted in the context of the dataset and its available fields.*

## Project Files
- `Customer_Shopping_Behavior_Analysis.ipynb` — Python analysis and exploratory data analysis.
- `Customer_Shopping_Behavior_Dashboard.pbix` — Power BI dashboard.

## Business Value
The analysis demonstrates how customer purchase data can help businesses understand product demand, evaluate customer preferences, and make better-informed marketing and inventory decisions.
